Comment lire ce plan

  • Mardi = footing facile · Mercredi = séance qualité · Vendredi = sortie longue · Dimanche = arbitrage (compte comme charge)
  • Clique sur "détail" pour voir la structure exacte (échauffement / bloc / récup) à rentrer dans Garmin
  • Coche une séance une fois faite pour suivre ta progression — la case à cocher est sur chaque ligne d'entraînement
  • Si pas de match un dimanche, active l'interrupteur pour voir la séance de remplacement
  • Renfo anti-essuie-glace après chaque course : leg raise latéral, clamshell, pont fessier unilatéral, marche latérale — 2-3 séries chacun
  • Une semaine sur quatre est allégée (marquée "récup") pour laisser le genou absorber la charge
  • Toute gêne au genou = on coupe la séance, sans exception, quelle que soit la phase
Ta progression (cases cochées) est sauvegardée dans le navigateur (localStorage). Ça fonctionne une fois le site déployé (Vercel, etc). Dans un aperçu/preview sandboxé, ça peut ne pas persister entre les rechargements.
